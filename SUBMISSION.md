## Feature status

### Implemented and verified
Verified by the integration tests, the API audit, and browser runs against the production build:

- [x] **Authentication:** sign in and out with seeded accounts; server-side sessions in `HttpOnly` cookies; invalid sign-ins rejected with a uniform message
- [x] **Document creation, renaming, editing, deletion** (owner only, with confirmation), and **reopening after refresh**
- [x] **Rich text:** H1–H3, bold, italic, underline, bulleted and numbered lists, undo/redo; formatting preserved after reload
- [x] **Autosave** with status (Saved / Saving… / Offline · retrying / Not saved), retry after network failure, sign-in prompt on expired session, unsaved-changes guard
- [x] **Conflict handling:** concurrent saves never silently overwrite (`409` → *Load their version* / *Keep mine*)
- [x] **File import:** `.docx`, `.md`, `.txt` (≤ 4 MB) become editable documents; invalid, corrupt, oversized, and zip-bomb files rejected with clear messages
- [x] **Sharing:** owner shares by email as viewer or editor, changes roles, revokes (with Undo); changes apply on the next request, even to open editors
- [x] **Permissions enforced server-side:** viewers can't edit, editors can't share or delete, other users get `404`
- [x] **Owned vs shared separation** on the dashboard, with role badges and search
- [x] **Responsive** layouts for phone, tablet, and desktop

### Partially implemented
- **Session-expiry recovery:** edits are kept and saving resumes after you sign in again in another tab, but there is no inline re-authentication dialog.
- **Text-style menu with very fast keyboard input:** reliable at human typing speed, but automated keystrokes under about 20 ms apart can be dropped by the menu component.

### Not implemented (deliberate scope cuts)
Real-time co-editing and presence, comments, version history, export, images, tables, and links in documents, sign-up and password reset, sign-in rate limiting, and import into an existing document. The reasons are in [ARCHITECTURE.md](./ARCHITECTURE.md#engineering-tradeoffs).

## Known limitations
- Demo authentication only (seeded accounts); `/api/users` lists the demo accounts to signed-in users for share suggestions.
- Dashboard search filters the loaded list in the browser; there is no pagination.
- Imported original files are not stored (metadata only).
- There is no committed browser end-to-end (Playwright) suite; browser behavior was verified with scripted, agent-driven runs.
